# Smart Loan Analytics & Management System (SLAMS)

## About the Project

SLAMS is a web-based system developed as an individual academic project for managing loan information, customer records, installments, and payments.

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* Bootstrap
* Chart.js
* XAMPP

## Main Features

* Admin login and user management
* Customer management
* Loan creation and management
* Installment generation and tracking
* Payment recording and history
* Overdue loan monitoring
* Dashboard and reports

## Installation

1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Import the sample database SQL file using phpMyAdmin.
4. Configure the database connection in the project configuration file.
5. Start Apache and MySQL in XAMPP.
6. Open `http://localhost/slams/` in your browser.

## Project Type

HNDIT Individual Academic Project – SLIATE

**Note:** Configure your own local database credentials before running the project. Do not publish passwords or sensitive data.
